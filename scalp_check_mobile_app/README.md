# Scalp Check: Android app

The phone app for the `scalp_cv` project. It runs the trained model **on the phone**:
no internet, no server, and photos are never saved or sent anywhere.

- **Screens:** Home, Scan (live camera), Result, "We are not sure", "This doesn't look like a scalp photo", Why we think so, Learn (list and detail), About.
- **Not-a-scalp check:** if `artifacts/gate.onnx` exists (trained by `src/train_gate.py`, see `GATE.md`), photos that aren't of the scalp or hair are rejected before the classifier runs.
- **Model:** loads the file named by `model_file` in `artifacts/preprocess_config.json`. In this repo that is `model_fp32.onnx`, because the export step found INT8 lost about 12 macro-F1 points (see `reports/export_benchmark.csv`).
- **Built with:** Vite (plain HTML/CSS/JS) + ONNX Runtime Web, packaged as an Android app with Capacitor.

This folder never changes the repo's files. It only **copies** the chosen model and three JSON files from `../artifacts/`.

---

## 1. Put this folder in the repo

```
scalp_cv/
├── artifacts/        <- your partner's files (unchanged)
├── src/ app/ ...     <- unchanged
└── mobile_app/       <- this folder
```

## 2. One-time setup

Install **Node.js LTS** and **Android Studio** (Standard setup), then in a terminal:

```
cd scalp_cv/mobile_app
npm install
```

## 3. Try it in a browser first (fast)

```
npm run dev
```

Open the address it prints (for example `http://localhost:5173`). In Chrome, press F12 and switch on the phone view.
`npm run dev` copies the model files from `../artifacts/` into `public/models/` automatically.

**Check the model was read correctly:** open `http://localhost:5173/#/check`. It shows the model file used,
image size, crop, mean/std, temperature, "not sure" threshold, the label list, and any warnings.
If there are warnings, fix them with `OVERRIDES` at the top of `src/model.js` (see section 6).

## 4. Build the Android app

```
npm run android
```

This builds the app, copies it into the `android/` project, and opens Android Studio. Then:

1. Wait for **Gradle sync** to finish (the bar at the bottom; slow the first time).
2. Plug in your phone (USB debugging on), pick it at the top, and press **Run ▶**.
3. For the file to submit: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
   The file appears at `android/app/build/outputs/apk/debug/app-debug.apk`. Rename it `ScalpCheck.apk`.

After any change to the code or the model, run `npm run android` again.

## 5. App icon

The icon is already generated from the Scalp Check logo (white hair strands on teal).
Source images are in `assets/`; a preview is in `docs/icon-preview.png`.
To change it, replace the images in `assets/` (1024×1024 px; splash 2732×2732 px) and run:

```
npm run icons
npx cap sync android
```

## 6. Making the app match `src/predict.py` exactly

The app reads `preprocess_config.json` and `calibration.json` and recognises common key names.
If `#/check` shows a warning, or `src/predict.py` does something different, set the exact values in
`OVERRIDES` at the top of `src/model.js`:

| Setting | Meaning | Example |
|---|---|---|
| `size` | final image size the model gets | `224` |
| `resizeShorter` | resize shorter side, then centre-crop (`0` = squash to size×size) | `256` |
| `mean`, `std` | normalisation | `[0.485, 0.456, 0.406]` |
| `temperature` | from temperature scaling | `1.37` |
| `threshold` | below this top score the app says "We are not sure" | `0.6` |

**Already checked:** with the repo's current files, the app reads `img_size` 224, `resize` 255, ImageNet mean/std,
temperature 0.544 and reject threshold 0.541, and loads `model_fp32.onnx`. On 6 real photos it gave the same top answer
as `src/predict.py` every time, with confidence within about 2 points.

**Parity test (repeat if the model changes):** run 5–10 test images through your partner's `src/predict.py`,
then through the app. The top answer should match, and the "out of 100" numbers should be within a few points
(small differences come from how the phone resizes images).

## 7. Things to fill in

In `src/content.js`:
- `APP.accuracyOutOf100`: your final test accuracy as a whole number (shown in About → "How accurate is it?").
- The condition descriptions: only seborrheic dermatitis has been checked against sources. **Have the other nine reviewed.**

Photos are in `public/samples/<key>.jpg` (Learn tab, one per condition) and `public/team/` (Meet the Team).

## 8. "Why we think so" screen

The phone can't run Grad-CAM++ (it needs the full PyTorch model), so this screen uses **occlusion**:
it covers one part of the photo at a time and measures how much the app's confidence drops.
It uses the same model and takes a few seconds. The Grad-CAM++ results stay in `reports/figures/` for the report.
